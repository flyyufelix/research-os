# Personal Notes

Use this procedure for the researcher's canonical notes, local notes to import, and exported notes. Keep personal thinking under `notes/`, not `library/`.

- Treat files already under `notes/` as canonical, editable researcher writing. Do not rewrite, expand, or append agent commentary unless explicitly requested.
- Accept personal notes with or without YAML front matter. Default new or imported canonical notes to plain Markdown and never require metadata for ingestion, retrieval, or manifesto updates.
- Import an eligible staged or exported note into `notes/` without rewriting its researcher-authored prose. Use a stable descriptive filename and avoid a second developed copy.
- If a source note already has front matter, preserve meaningful author metadata but remove transport-only, staging-only, or demo-only fields such as `created_for_demo` unless the researcher asks to retain them.
- Treat `staging-material/` and similar locations as disposable staging. Never make a durable link depend on a staging path.
- Preserve meaningful external provenance such as a Notion page ID or URL when available, but do not retain a staging-file path merely for provenance.
- Identify new or modified canonical notes from user-specified paths first, then version-control changes or modification dates when available.
- Compare each relevant note with `manifesto.md`, related personal notes, and relevant external source notes.
- Keep researcher statements, source-supported claims, agent inference, and open uncertainty distinct in the manifesto and task report.
- Sense possible research direction or taste only from explicit statements or recurring patterns across notes. Label inferred preferences and state confidence.
- Do not turn a single ambiguous remark into a stable preference.
- Link manifesto questions, hypotheses, preferences, and decisions directly to the relevant files under `notes/`.
- Promote only durable and retrieval-useful material; a personal note may require no manifesto change.
- Do not require `notes/inbox.md`, `notes/ideas/`, or any other intermediate note layer.
