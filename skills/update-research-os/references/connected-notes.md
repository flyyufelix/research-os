# Connected Notes

Use this procedure for Notion, OneDrive, Obsidian, Google Drive, or another connected note system.

- Access the system only after the researcher explicitly authorizes the connection and scope.
- Prefer read-only MCP or connector access. Treat the external system as the source of truth unless told otherwise.
- Retrieve only pages or files relevant to the research task; do not ingest an entire workspace by default.
- Record the system, page or file ID, URL or path, original modification date, access date, and processing status when available.
- Resolve the source of truth before importing. If the Research OS is primary, import the selected note into `notes/` and treat that local copy as canonical. If the connected system remains primary, create or refresh a clearly marked local mirror under `notes/` and retain its stable page or file ID and URL.
- Preserve researcher-authored content during import or refresh. Do not create a separate developed interpretation under `notes/ideas/`.
- Link the manifesto to the corresponding note under `notes/`; let that note carry any stable link back to the connected source.
- Do not silently write back, reorganize, or modify the external system.
- If an authorized connection is unavailable, request a Markdown or PDF export, pasted text, or a readable local folder.
