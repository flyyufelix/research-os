Connect Research OS to an AI agent

The folder structure and prompts stay the same across agent frameworks. Start with one of the tested recommendations below, or use another capable agent you prefer.

Four tested recommendations

These four agents have been tested with the local project, manifesto workflow, and Literature Scout. They are recommended starting points, not a compatibility limit, and no option is ranked above another.

ChatGPT WorkOpen the repository as a local project and use its included skill discovery files.› Tencent WorkBuddyCreate a local task with the Research OS folder as its working directory.› QwenWorkUse the desktop app for direct access to the Research OS folder and workflows.› Doubao WorkCreate a work task and authorize the Research OS folder as its local project.›
Prefer another agent? Research OS is framework agnostic. Other agents may also work when they can read and write the project folder, follow AGENTS.md, and run the included workflow instructions.

The shared workflow

  1. Open the correct folder

    Select the directory containing AGENTS.md, skills/, and staging-material/.

  2. Keep permissions narrow

    Allow the agent to work inside the Research OS directory. Review consequential file operations rather than granting access to your whole computer.

  3. Use plain-language prompts

    The repository contains the detailed workflow. Your prompt can remain short.

  4. Review the files

    Check the manifesto, source notes, and scout reports in the folder instead of relying only on the agent’s chat summary.

Core prompts

First build

Build my Research OS using everything in staging-material.

Add a source

Index the attached paper and update my Research OS.

Scout the literature

Run Literature Scout once using scout/scope.md. Save the dated report, but do not index candidates or change manifesto.md.

If a workflow does not start

Use an explicit prompt that points to the canonical workflow. This does not change the workflow; it only tells the agent where to read it.

Read AGENTS.md and skills/bootstrap-research-os/SKILL.md completely, then build my Research OS using everything in staging-material.

If the agent still cannot read the file, check that you opened the repository root and granted access to that folder.
