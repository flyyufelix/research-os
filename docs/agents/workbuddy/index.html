Agent setup

Use Research OS with Tencent WorkBuddy

Create a local task, make the Research OS repository its working directory, and let WorkBuddy produce the research files inside that boundary.

Research OS flow: verifiedLast verified: September 2026Official documentation

Setup

  1. Install and open WorkBuddy

    Use the Tencent WorkBuddy desktop application and start a new local task.

  2. Choose the working directory

    Select the Research OS folder that contains AGENTS.md. WorkBuddy reads and saves files within the selected directory.

  3. Use default permissions first

    Review sensitive file changes and actions outside the workspace. Broad access is not required for the Research OS workflow.

  4. Start the first build

    Build my Research OS using everything in staging-material.

Verify the result

  • manifesto.md exists and remains pending your review.
  • Your initial ideas are preserved under notes/.
  • External evidence is indexed under library/.
  • WorkBuddy reports incomplete or inaccessible material instead of inventing coverage.

Run Literature Scout

Run Literature Scout once using scout/scope.md. Save the dated report, but do not index candidates or change manifesto.md.

For a scholarly MCP, go to Settings → MCP, add the server URL or configuration, and complete OAuth if the server uses it. Start with the official OpenAlex connection.

If WorkBuddy misses the workflow

Confirm that the task’s working directory is the Research OS root. Then use the canonical file explicitly:

Read AGENTS.md and skills/bootstrap-research-os/SKILL.md completely, then build my Research OS using everything in staging-material.
