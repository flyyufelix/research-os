Agent setup

Use Research OS with ChatGPT Work

Open the local repository as a project, let ChatGPT discover the included workflows, and keep your research files in one working directory.

Research OS flow: verifiedLast verified: September 2026Official quickstart

Setup

  1. Install and sign in

    Use the ChatGPT desktop app. Start from ChatGPT and select Work for research and file-based tasks.

  2. Open the Research OS folder

    Create or open a local project using the folder that contains AGENTS.md. ChatGPT can then read and update files within that project.

  3. Confirm the workflow is available

    The repository includes discovery loaders under .agents/skills/. ChatGPT can select the matching bootstrap, update, or literature-scout workflow from your request.

  4. Start the first build

    Build my Research OS using everything in staging-material.

Verify the result

  • manifesto.md exists and says Awaiting review.
  • notes/research-origin.md preserves your initial ideas.
  • The library index and source notes describe actual reading coverage.
  • The task asks for approval rather than silently publishing the manifesto.

Run Literature Scout

Edit scout/scope.md, then run one manual test:

Run Literature Scout once using scout/scope.md. Save the dated report, but do not index candidates or change manifesto.md.

For external research services, open Plugins or the relevant connection settings. Connect only services you trust and review the requested permissions. See the MCP guide.

If ChatGPT does not select the workflow

  • Confirm the project root contains .agents/skills/.
  • Start a new task after downloading or updating the repository.
  • Use the explicit fallback below.
Read AGENTS.md and skills/bootstrap-research-os/SKILL.md completely, then build my Research OS using everything in staging-material.
