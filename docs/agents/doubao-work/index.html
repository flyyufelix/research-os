Agent setup

Use Research OS with Doubao Work

Run Research OS as a local work task so Doubao can read the project, create the manifesto, and save scout reports in the repository.

Research OS flow: verifiedLast verified: September 2026Official product page

Setup

  1. Open Doubao Work

    Use the current desktop application and create a new work task rather than a standard chat.

  2. Enable the local computer project

    Choose the Research OS folder as the project directory. Select the folder containing AGENTS.md, not the parent folder.

  3. Review the folder permission

    Authorize access only to the Research OS project. Generated research files should remain inside this directory.

  4. Start the first build

    Build my Research OS using everything in staging-material.

Verify the result

  • The task creates manifesto.md inside the selected project.
  • The manifesto remains pending your review and preserves uncertainty.
  • Source records state which pages or sections were examined.
  • No durable Research OS file links back to disposable staging locations.

Run Literature Scout

Run Literature Scout once using scout/scope.md. Save the dated report, but do not index candidates or change manifesto.md.

Use Doubao’s available web or research tools for the baseline run. If your current version offers a custom connector or MCP entry, follow its current in-product instructions; otherwise keep the run web-based and record that structured scholarly coverage was unavailable.

If Doubao misses the workflow

Read AGENTS.md and skills/bootstrap-research-os/SKILL.md completely, then build my Research OS using everything in staging-material.

If files appear in a separate task directory, create a new work task and explicitly choose the Research OS repository as the local project before sending the prompt.

Product reference: Doubao Work. Interface availability can vary by application version and account.
