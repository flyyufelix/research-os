Agent setup

Use Research OS with QwenWork

Use the desktop application for direct local-file access, then run the Research OS workflows from the repository itself.

Research OS flow: verifiedLast verified: September 2026Official quickstart

Setup

  1. Install the desktop app

    The desktop version can work directly with local files. Sign in and start a new task.

  2. Add the Research OS folder

    Select or attach the folder that contains AGENTS.md. Keep the project root available as the task’s working context.

  3. Point QwenWork to the repository workflow

    Describe the task normally. If needed, name the canonical workflow file so QwenWork reads the full instructions before acting.

  4. Start the first build

    Build my Research OS using everything in staging-material.

Verify the result

  • manifesto.md records the current research direction and uncertainty.
  • Your original ideas remain preserved in notes/research-origin.md.
  • Source notes distinguish mapped material from closely read material.
  • The proposed manifesto waits for explicit approval.

Run Literature Scout

Run Literature Scout once using scout/scope.md. Save the dated report, but do not index candidates or change manifesto.md.

QwenWork manages external services through Extensions → Connectors. Use a supported scholarly connector when available; otherwise run the scout with ordinary web search and record the coverage limitation.

If QwenWork misses the workflow

Read AGENTS.md and skills/bootstrap-research-os/SKILL.md completely, then build my Research OS using everything in staging-material.

If it cannot open the files, use the desktop application and add the repository root as folder context. In QwenWork, @ adds files or folders to context; it does not invoke a skill.

Platform references: QwenWork Quick Start, Skills, and Connectors.
