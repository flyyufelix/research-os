First build

Build your first research manifesto

Begin with rough ideas and optional source material. The included workflow maps what you provide, drafts a working research direction, and leaves the final approval to you.

Before you start

You need a local copy of Research OS and an AI agent that can work with a project folder. Git is optional. You can read every output in Obsidian or any text editor.

Your goal for this guide

Finish with a proposed manifesto.md marked Awaiting review. Approval happens only after you check the draft.

1. Download Research OS

Without Git

Download the ZIP, open it, and move the extracted research-os-main folder somewhere easy to find.

Download ZIP

With Git

Clone the repository so you can pull future updates.

git clone https://github.com/flyyufelix/research-os.git

2. Write your starting ideas

Open staging-material/ideas.md and replace its placeholder text. Fragments are fine. Include disagreements and uncertainty rather than forcing a clean thesis too early.

# My starting point

## Topic or problem
What am I trying to understand?

## Questions
- What is my main question?
- What smaller questions support it?

## Current hunches
- What do I currently suspect?
- What might prove me wrong?

## Scope and boundaries
- Who, where, and what period am I studying?
- What is outside this project?

## Research preferences
- What kinds of evidence do I trust most?
- Which methods, disciplines, or perspectives matter?

## Known sources and gaps
- What have I already read?
- What evidence is still missing?

You are not writing manifesto.md yet. Your agent will synthesize the manifesto from this preserved starting point and any other material you add.

3. Add material if you have it

  • Put papers, theses, reports, or PDF books in staging-material/papers/.
  • Put your own Markdown notes in staging-material/personal-notes/.
  • Leave these folders empty if you are beginning with ideas alone.

The bootstrap workflow first maps the whole collection. It reads deeply only where the material could affect a central question, hypothesis, definition, or decision.

4. Open the folder in an AI agent

Select the folder that directly contains AGENTS.md, skills/, scout/, and staging-material/. Do not select the parent Downloads folder.

ChatGPT WorkOpen a local project folder in the desktop app.› Tencent WorkBuddyCreate a local task with the Research OS working directory.› QwenWorkUse the desktop app with access to the local folder.› Doubao WorkUse a work task with the local computer project enabled.›

5. Run the first build

Start a new task in the project and send this prompt:

Build my Research OS using everything in staging-material.

The agent should preserve your original ideas.md as notes/research-origin.md, map your sources, and create a provisional manifesto. Long books are mapped and selectively read rather than treated as fully examined.

6. Review the result

Before approving anything, check these outputs:

  • manifesto.md states the question, scope, working hypotheses, uncertainties, evidence gaps, and next decisions.
  • notes/research-origin.md matches your initial ideas without silent rewriting.
  • library/_index.md lists the external sources that were processed.
  • Each source note states what material was actually examined and what remains unread.
  • Claims from sources link to library/; your own thinking links to notes/.
  • The manifesto is proposed as v0.1.0 with status Awaiting review.

Approval is a real checkpoint

The AI agent prepares the research position; you approve it. Ask for revisions if the manifesto misstates your ideas, overstates evidence, or removes productive disagreement.

Explore the completed music-and-studying example to compare its raw ideas, personal notes, papers, source records, manifesto, and scout report.

7. Approve or revise

If the draft is accurate, approve it explicitly:

I have reviewed manifesto.md and approve the proposed v0.1.0. Publish this version according to the Research OS versioning workflow.

Approval creates the first immutable manifesto snapshot and changelog entry. If the draft needs work, describe the changes instead of approving it.

What comes next

Once the manifesto reflects your current direction, use Literature Scout to look for evidence that fills or challenges its gaps.
